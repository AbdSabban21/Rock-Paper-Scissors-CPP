# Rock Paper Scissors Game - C++ Console Application

A simple console-based Rock Paper Scissors game built using C++.

This project was created to practice problem solving, clean code, functions, enums, random choices, scoring, and full game flow management.

---

## Project Description

This project allows the player to play Rock Paper Scissors against the computer.

The player chooses one of three options:

- Rock
- Paper
- Scissors

The computer randomly selects its choice, then the program compares both choices and decides the winner of each round.

At the end of the game, the program displays the final result based on the number of rounds won by the player and the computer.

Although this is a simple game, it combines many important programming concepts into one complete console application.

---

## Features

- Player vs Computer gameplay
- Random computer choice
- Multiple rounds
- Round result detection
- Score tracking
- Final winner calculation
- Replay option
- Console screen color changes based on the result
- Organized code using functions and enums

## How to Run

### Option 1: Using Visual Studio

1. Open Visual Studio.
2. Create a new C++ Console Application project.
3. Open or copy the `RockPaperScissors.cpp` file into the project.
4. Build and run the project.

### Option 2: Using any C++ compiler

Compile the file using a C++ compiler:

```bash
g++ RockPaperScissors.cpp -o RockPaperScissors
```

Then run it:

```bash
./RockPaperScissors
```

On Windows CMD, run:

```bash
RockPaperScissors.exe
```
